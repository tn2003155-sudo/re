# レシート → スプレッドシート

レシート画像を Claude で読み取り、**日付・店名・購入品目(数量・単価・金額)** を Excel (.xlsx) にまとめます。

## セットアップ

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...
```

## 使い方

```bash
# フォルダ内の画像 (jpg / png / gif / webp) をまとめて処理
python receipt_to_xlsx.py receipts/ -o receipts.xlsx

# ファイルを個別に指定
python receipt_to_xlsx.py IMG_0001.jpg IMG_0002.png
```

## 購入品名のまとめ方

参考スプレッドシート「レシートデータのエクセル・CSV化」と同じく、**1レシート = 1行** で
購入品名を「区分（主な品目）」のシンプルな形にまとめます。

例: `タクシー代` / `飲食代` / `雑貨（トイレットペーパー）` / `事務用品（輪ゴム）` / `飲料（Y1000）`

区分は参考シートで使われているもの（タクシー代・交通費・飲食代・雑貨・事務用品・PC用品・
医薬品・書籍・通信費・会費 など）を既定で使います。区分を差し替えたい場合は、1列目に区分を
並べた CSV / TXT を `--names` で渡してください。

```bash
python receipt_to_xlsx.py receipts/ --names names.csv
```

## 出力

| シート | 内容 |
| --- | --- |
| Master | 全レシート。日付 / 店名 / 購入品名 / 金額（参考シートと同じ列） |
| 1月, 2月, … | 月別に分けた同じ表 |
| 明細(確認用) | 読み取った商品行。商品合計とレシート合計がずれる場合は差額行を表示 |

大きな画像は送信前に自動で縮小します。
